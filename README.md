# Púlpito Digital — versão Android offline

Esta é a edição pública sem chave YouVersion. A consulta online à Bíblia fica desativada; passagens previamente inseridas nos sermões podem ser lidas offline.

## Publicação
1. Faça upload dos arquivos desta pasta para a raiz do repositório `pulpito-digital-app` na branch `main`, incluindo `.github/workflows/deploy.yml`.
2. Em Settings > Pages > Source, selecione **GitHub Actions**.
3. Acompanhe a execução em Actions; quando concluir, abra `https://pastornilsonteixeira-stack.github.io/pulpito-digital-app/`.
4. No Android Chrome, escolha Instalar aplicativo / Adicionar à tela inicial; abra uma vez com internet antes de testar em modo avião.

## Dados e privacidade
Os sermões ficam no armazenamento local do navegador do dispositivo. **Não são sincronizados** com o Mac. Exporte backup JSON no Mac e importe no tablet. Não limpe os dados do site sem antes exportar backup. Nunca envie `.env`, chaves ou arquivos de backup ao GitHub. A página publicada é acessível a qualquer pessoa com o link, mas não contém os sermões privados do usuário.
